# Contributing

Thank you for considering contributing to this project! The prompt is a living document, and edge cases in AI generation are always appearing.

## How to Contribute

### Reporting Issues
If the prompt fails to fix a specific piece of Markdown, or if it breaks something that should have been preserved:
1. Open a **New Issue**.
2. Attach a sample of the **broken Markdown** input.
3. Describe what the prompt did wrong (e.g., "It deleted my table" or "It didn't fix the nested code block").

### Suggesting Improvements
1. Fork the repository.
2. Edit `PROMPT.md` with your proposed changes.
3. Submit a **Pull Request**.
4. Please explain **why** the change is needed and provide a before/after example if possible.

## Principles
- **Safety First**: We prioritize *not breaking* content over *perfectly formatting* it.
- **Obsidian Focus**: Changes should specifically benefit compatibility with Obsidian.
