# Custom GPT Prompt-Fix & Normalize AI-Generated Markdown for Obsidian

This repository hosts the [prompt](PROMPT.md) used for the "Fix and Normalize AI Generated Markdown for Obsidian" Custom GPT.

## Purpose
This prompt allows you to take messy, broken, or inconsistent Markdown generated by AI tools (like Perplexity, ChatGPT, or Claude) and "normalize" it for use in **Obsidian**.

It focuses purely on **structural repair**, ensuring that the content renders correctly without changing the actual text.

## Key Features

### 🛠️ Structural Repair
- **Code Fences**: Fixes nested fences, mixed backticks (``` vs ````), and missing closures.
- **Tables**: Repairs spacing issues, leading spaces, and broken pipe structures.
- **Content Protection**: Wraps directory trees, ASCII diagrams, and CLI output in code blocks to prevent layout breakage.

### 💎 Obsidian Optimization
- **Heading Normalization**: Enforces a consistent heading hierarchy (Baseline Level 2), shifting all headings uniformly to avoid massive H1 titles or deep nesting.
- **Clean Syntax**: Removes redundant horizontal rules and bold/italic styling from headers.
- **Strict Formatting**: Enforces standard CommonMark compliance (triple backticks only).

### 🔒 Safety & Preservation
- **Zero Data Loss**: Explicitly forbidden from summarizing, trimming, or rewriting prose.
- **No Editorializing**: Fixes the *syntax*, not the *style*.
